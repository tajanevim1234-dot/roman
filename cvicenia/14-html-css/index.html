Čo si zapamätať

Relatívna cesta ../js/nav.js
.. ide o priečinok vyššie, potom do js a načíta súbor nav.js.
Atribút defer
Externý skript sa sťahuje počas spracovania HTML, ale vykoná sa až po jeho spracovaní. Skripty s defer zachovajú poradie.
id a class
id je jedinečný identifikátor prvku (CSS: #rozvrh). Rovnakú class môže mať viac prvkov (CSS: .cards).
