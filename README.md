# Príprava na zápočet

Začni tu: [prehľad 15 samostatných cvičení](cvicenia/README.md).

Každé cvičenie má vlastné zadanie. Cvičenia 1–10 obsahujú tvoje doterajšie riešenia, cvičenia 11–15 sú doplnené a okomentované po slovensky.

HTML otvor cez Live Server. Cvičenia 11 a 15 potrebujú HTTP server kvôli načítaniu JSON; mapa v cvičení 12 potrebuje aj internet.
